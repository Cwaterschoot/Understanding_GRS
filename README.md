# Understanding_GRS
Repository for the paper 'Evaluating the Understandability of Social Choice-based Explanations for Group Recommendation'

## Content:
This repository includes the following:

* **EvaluatingUnderstandability-code.ipynb**:
  
  This notebook contains all code to format the survey data, perform statistical tests discussed in the study and plot all figures/tables included in the paper.

* **understandability-correct-responses.csv**:
  
  The dataset containing the correct responses to the survey questions. Used for calculating objective understanding accuracy for each participant
  
* **full-survey-data.csv**:

  The full survey dataset containing all responses and timing variables derived from the experiment

* **understanding-data-for-statistics.csv**:

  Already formatted data which can be used to reproduce the statistical tests and statistics presented in the tables/figures

* **all_scenarios_understandability.pdf**:

  File containing all group scenarios (tables), all textual and graphical explanations and all survey questions (model simulation, counterfactual, error detection)
